type check took most of the time of tsec-compile-check, and the compilation already does it
with tsgo. On a local machine, tsec-compile-check now takes about 20 seconds instead of about 80,
and uses about 4.3 GB of memory instead of 6.4 GB.

- Add build/lib/tsec.ts, which builds the program of src/tsconfig.tsec.json and runs only the
  tsec rules, with the compiler host and reporter of tsec.
- Run that script in the tsec-compile-check script, which the PR workflow, the product quality
  checks and the tsec-compile-check task use.
