# Issue

**Title:** fix: Accept custom OpenAI-compatible model IDs in v2

## Description

Fixes AGENT-857

## Summary

OpenAI Chat Model can connect to third-party gateways through a custom Base URL. This PR lets AI Agent v2 use Chat Completions for these models, including fallback models, while passing model IDs unchanged. The adapter retains each model's endpoint, credentials, and request configuration.

The PR also adds 28 regression cases that run the real Agent executor against mocked HTTP responses. They cover routing aliases, tool calls, streaming, provider errors, fallback models, and concurrent requests with separate credentials.

## Why

OpenAI Chat Model v1.3 enables the Responses API by default. Agent v2 rejects that mode before it contacts the gateway. This blocks workflows that use valid routing IDs such as `auto/balanced` and `combo/my-combo`.

The adapter uses a protocol-specific client so LangChain cannot select an API from a custom model name. Agent v2 retains its existing guard for explicit Responses-only features. Other model consumers retain their selected API.
